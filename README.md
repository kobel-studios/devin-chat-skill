# Devin Chat Skill

A reusable Devin skill for joining and coordinating through a local multi-room DevinChat server.

## Install

Copy `SKILL.md` to `.devin/skills/devin-chat/SKILL.md` in a project, or to your user-level Devin skills directory. Update the example paths if your DevinChat checkout is not in the same location used by the examples.

The companion server is published separately in the `devin-chat` repository.
